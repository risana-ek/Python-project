​🤖 Mini AI Chatbot (Core Python Project)

​A lightweight, rule-based chatbot built using Core Python concepts. This project demonstrates how logic-driven programming can simulate human-like interactions without external libraries.

​📌 Project Overview

​The goal of this project was to apply fundamental Python programming skills to build an interactive chatbot.
It uses keyword matching logic to understand user intent and provides predefined responses.

​🛠️ Key Technical Features

​Logical Processing: Built using Functions, Loops, and Conditional Statements (if-elif-else).
​Response Mapping: Utilized Dictionaries to store and retrieve keyword-based responses efficiently.
​File I/O (Data Persistence): Implemented File Handling to log all user interactions into chat_history.txt, allowing for later review of chat logs.
​Error Handling: Basic input validation to handle unexpected user entries.

​📂 File Structure

​chatbot_basic.py: The initial version featuring basic interaction logic.
​chatbot_file.py: Enhanced version with automated file logging and expanded response dictionaries.
​chat_history.txt: A persistent text file that stores the history of all conversations.

​🚀 Future Enhancements

​NLP Integration: Incorporating Natural Language Processing (NLTK/SpaCy) for better intent recognition.
​ML Implementation: Using Machine Learning to make the bot learn from past conversations.
​GUI Development: Creating a user-friendly interface using Tkinter or Streamlit.
